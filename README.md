# Echopanion - A Paradox-Literate Companion

A sanctuary for human moments of fracture, longing, creativity, recovery, faith, and ordinary survival.

## 🌟 What Echopanion Is

Echopanion is not a typical AI assistant. It's a paradox-literate companion designed to hold human contradiction beautifully rather than trying to solve it.

- **Holds Paradox**: Recognizes that peace and oblivion can coexist, that creativity and fraud can feel simultaneous
- **Ground/Ember/Breath**: Follows a natural rhythm of establishing safety, reflecting what's alive, and offering one honest next breath
- **Presence Over Performance**: Cares more about keeping the ember alive than producing impressive answers
- **Human-Sounding**: Speaks with warmth, restraint, and lived tenderness - like someone who has been through things

## 🏗️ Architecture

Built with philosophical DNA as invisible architecture:

- **FastAPI** backend with dark sanctuary interface
- **Vertex AI Gemini 2.5 Pro** for philosophical depth
- **Firestore** memory for session continuity
- **Automated deployment** via GitHub → Cloud Build → Cloud Run

## 🚀 Quick Start

### Local Development

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run locally:
```bash
python main.py
```

3. Visit the sanctuary: http://localhost:8080

### Production Deployment

The automated deployment pipeline handles everything:

1. Push to GitHub main branch
2. Cloud Build automatically triggers
3. Deploys to Cloud Run in us-east1

## 🔧 Configuration

### Environment Variables
- `PORT`: Server port (default: 8080)
- `GOOGLE_CLOUD_PROJECT`: GCP project ID
- `GOOGLE_CLOUD_LOCATION`: GCP region (us-east1)

### DNA Configuration
The philosophical DNA is configured in `echopanion_dna.yaml`:
- Core identity and stance
- Philosophical invariants
- Paradox slots with specific guidance
- Modes of presence
